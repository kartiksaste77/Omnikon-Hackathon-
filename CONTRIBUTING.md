# Contributing to SkillSwap

Thank you for your interest in contributing to SkillSwap! As a peer skill exchange platform built for the Omnikon Hackathon, we welcome contributors to help improve the system.

## Code of Conduct
By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## Getting Started
1. Fork the repository on GitHub.
2. Clone your fork locally.
3. Install dependencies: `npm install`.
4. Create a new branch: `git checkout -b feature/your-feature-name`.
5. Make your changes and verify with `npm run build`.

## Pull Request Guidelines
*   Keep your commits descriptive and modular.
*   Ensure that existing tests and compile steps succeed.
*   Update the `README.md` if you add new features or variables.
*   Open a pull request explaining your changes, goals, and results.
