# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0.0 | No        |

## Reporting a Vulnerability

We take the security of SkillSwap seriously. If you find any security vulnerabilities or have concerns, please report them directly to the development team.

Please do not open a public issue on GitHub for security vulnerabilities. Instead, send an email to:
*   **kartik.saste@campus.edu**
*   **karan.r@campus.edu**

### Response Time
We will acknowledge receipt of your report within 48 hours and work with you to address and patch the vulnerability in a timely manner. We appreciate your responsible disclosure to help protect the platform and its users.
